# دروب الحمراء · Duroob Al-Hamra

لعبة تعليمية ثلاثية الأبعاد لتعلّم العربية مع سالم في قرية الحمراء العُمانية، مبنية بمحرّك Three.js مخصّص.

## الملف الجاهز للعب

[`game/Duroob-Al-Hamra.html`](game/Duroob-Al-Hamra.html) — افتحه مباشرة في أي متصفح حديث (Chrome / Edge / Safari يُفضَّل لدعم التعرّف على الكلام). لا يحتاج تثبيتًا أو خادمًا، لكن الميكروفون (تسجيل النطق) يحتاج رابط **https** أو خادمًا محليًا — فتحه كملف محلي (`file://`) قد يمنع المتصفح من الميكروفون.

## بنية المشروع

```
src/           المصدر المقسّم (يُعاد تجميعه في ملف اللعبة الواحد)
  head.html    رأس الصفحة والـ CSS والخطوط المضمّنة
  world1/2/3.js محرك القرية ثلاثي الأبعاد (Three.js): التضاريس والبيوت والشخصيات والتحكم
  sound.js     النطق الآلي، التسجيل، وتقييم النطق كلمة بكلمة
  gloss.js     الترجمة الإنجليزية والنطق بالحروف اللاتينية لكل عبارة في اللعبة
  lessons.js   منطق الدروس الثلاثة (الحارة، السبلة، المسجد)
  main.js      حالة اللعبة، الحفظ المحلي، شاشة البداية والإعدادات
  tail.html    نهاية الصفحة (تراخيص الخطوط والمكتبات)
build.pl       يدمج كل ملفات src/ في game/Duroob-Al-Hamra.html (Perl)
game/original.html  النسخة الأصلية قبل إعادة البناء (للمرجع فقط)
```

## إعادة البناء بعد تعديل أي ملف في src/

```bash
perl build.pl
```

يُنتج `game/Duroob-Al-Hamra.html` من جديد. يحتاج Perl فقط (متوفر افتراضيًا على معظم الأنظمة، ومع Git for Windows / WSL على ويندوز).

## المعاينة المحلية

```bash
powershell -NoProfile -Command "Invoke-Expression (Get-Content -Raw serve.ps1)"
```

يشغّل خادمًا محليًا بسيطًا على `http://localhost:8765` (مفيد لتجربة الميكروفون، الذي يحتاج https أو localhost).

## ملاحظات

- الصوت العربي يعتمد صوت النظام إن وُجد، وإلا ينتقل تلقائيًا إلى صوت عبر الإنترنت (قابل للإيقاع من الإعدادات).
- التسجيل والتعرّف على الكلام أدق في Chrome / Edge / Safari؛ في Firefox يعمل بتقييم تقريبي فقط لعدم دعمه SpeechRecognition.
